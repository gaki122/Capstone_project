Images & Pixels

Learn how computers represent pictures using pixels, colors and digital information.

🖼️ What is a Digital Image?

A digital image is a picture that is stored inside a computer or digital device.

Computers represent images using many small individual elements called pixels.

Think of a Pixel as a Tiny Square

When many tiny pixels are placed together, they form the complete picture that we see on a screen.

🔲 What is a Pixel?

A pixel is the smallest individual element of a digital image.

Each pixel contains information about its color and brightness.

📐 Image Resolution

Image resolution describes how many pixels are used to create an image.

An image with more pixels can usually show more detail than an image with fewer pixels.

640 × 480 Low resolution example
1920 × 1080 Full HD example
3840 × 2160 4K example

🎨 How Do Pixels Store Color?

Digital images commonly use the RGB color model.

RGB stands for:

🔴 Red

🟢 Green

🔵 Blue

Different combinations of red, green and blue values can produce many different colors.

⚙️ How Does a Computer Store an Image?

A digital image is processed through several stages before it appears on your screen.

1

Pixels

The image is divided into many small pixels.

2

Color

Each pixel receives color information.

3

Numbers

Color information is represented using numerical values.

4

Binary

The numerical information is stored digitally using bits.
