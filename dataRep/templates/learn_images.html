DATA REPRESENTATION · LESSON 3

Learn Image Representation

Discover how computers represent pictures using pixels, binary numbers, resolution, colour depth, and digital storage. Learn the concepts step by step with examples and an interactive storage calculator.

1. What Is Image Representation?

Image representation is the way a computer stores and processes a picture using digital information. Instead of storing a physical picture, a computer represents the image using numbers in binary form.

Most digital photographs and screenshots are made up of tiny picture elements called pixels. Each pixel stores information about a small part of the image, such as its colour or brightness.

Remember: A digital image is represented using digital information that a computer can store as binary digits (0s and 1s).

2. Understanding Pixels

A pixel is the smallest individual element of a digital image. An image contains many pixels arranged in rows and columns. When viewed together, these pixels form a complete picture.

Illustration: each square represents one pixel.

Fewer Pixels

An image with fewer pixels contains less spatial detail and may look blocky when enlarged.

More Pixels

An image with more pixels can show finer detail, provided the image contains that detail.

3. What Is Image Resolution?

Resolution describes the number of pixels in an image. It is commonly written as width × height.

Image dimensions Total pixels Explanation
100 × 100 10,000 A small image
800 × 600 480,000 A medium-sized image
1920 × 1080 2,073,600 A Full HD image
Formula:
Total pixels = Width × Height

For example, an image that is 800 pixels wide and 600 pixels high contains:

800 × 600 = 480,000 pixels

4. Understanding Colour Depth

Colour depth, also called bit depth, describes how many bits are used to represent each pixel's colour. More bits allow a pixel to represent more possible colour values.

1-bit image

Each pixel uses 1 bit. It can represent 2 possible values, such as black and white.

2¹ = 2 values

8-bit grayscale

Each pixel uses 8 bits and can represent 256 brightness levels.

2⁸ = 256 values

24-bit RGB colour

A common uncompressed format uses 8 bits each for red, green, and blue.

8 + 8 + 8 = 24 bits per pixel

Number of colours

A 24-bit RGB pixel can represent up to 16,777,216 colour combinations.

2²⁴ = 16,777,216

Important: A higher bit depth allows more possible colour values. Actual image appearance also depends on the image content, display, and file format.

5. How Are Image Colours Stored in Binary?

Computers use binary digits: 0 and 1. In a common 24-bit RGB image, each pixel has three colour components: red, green, and blue. Each component is represented by 8 bits.

Colour component Decimal value 8-bit binary
Red 255 11111111
Green 0 00000000
Blue 0 00000000

These values represent a fully red RGB pixel: red is at its maximum value, while green and blue are zero.

RGB means Red, Green, and Blue. Combining different amounts of these three components produces a wide range of colours.

7. Common Image File Formats

Digital images can be saved in different file formats. Each format has its own features and suitable uses.

JPEG / JPG

Commonly used for photographs. It usually uses lossy compression to reduce file size.

PNG

Supports lossless compression and transparency. It is useful for logos, screenshots, and diagrams.

GIF

Supports simple animation and a limited palette of up to 256 colours per frame.

SVG

A vector format that describes shapes and paths. It can be resized without the same pixelation associated with raster images.

8. What Is Image Compression?

Image compression reduces the amount of data needed to store an image. This can save storage space and make images faster to transfer over a network.

Lossless compression

Reduces file size while preserving the original image data. PNG is a common example.

Lossy compression

Reduces file size by discarding some image information. JPEG commonly uses this method.

Example: A compressed photograph may take up less storage space than an uncompressed version, but the exact reduction depends on the image and compression settings.

9. Advantages and Limitations of Digital Images

Advantages

  • Easy to store and share.
  • Can be edited using software.
  • Can be copied and backed up.
  • Compression can reduce storage requirements.

Limitations

  • High-resolution images can use substantial storage.
  • Enlarging a small raster image can make it look pixelated.
  • Lossy compression may reduce image quality.
  • Different file formats have different capabilities.

10. Self-Learning Notes

Use these notes to revise the important concepts before starting the Image Representation game.

Note 1: Learn the key terms

  • Pixel: A small element of a digital image.
  • Resolution: The image dimensions in pixels.
  • Colour depth: The number of bits used to represent each pixel's colour.
  • RGB: Red, Green, and Blue colour components.
  • Compression: A way to reduce the amount of data stored.

Note 2: Memorise the formulas

  • Total pixels = Width × Height
  • Image bits = Total pixels × Bits per pixel
  • Bytes = Bits ÷ 8
  • For 8-bit values, the number of possible values is 2⁸ = 256.

Note 3: Understand image quality

Resolution and colour depth describe different properties. Resolution tells you how many pixels an image contains, while colour depth tells you how many bits are used for each pixel's colour information.

Note 4: Understand storage estimates

If two uncompressed images have the same dimensions but different bits per pixel, the image using more bits per pixel requires more pixel-data storage. Compressed file sizes also depend on image content and compression method.

Note 5: Practise with everyday examples

  • Check the dimensions of a photo on your phone.
  • Compare the file sizes of two photographs.
  • Look at the file extensions of images saved on your computer.
  • Use the storage calculator to try different resolutions.
Before you move on: Make sure you can explain pixels, resolution, colour depth, RGB, binary values, and image compression in your own words.
