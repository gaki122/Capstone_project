Learn Text Representation

Discover how computers store and process letters, words, numbers, and symbols. Learn about character encoding through simple notes, practical examples, and an interactive activity.

Start Learning ← All Learning Topics

1. What Is Text Representation?

Text representation is the way a computer stores and processes written information. This includes letters, numbers, punctuation marks, spaces, and special symbols.

Humans can read words such as Hello, but a computer stores information using binary digits called bits. A bit can have only one of two values: 0 or 1.

Remember: Computers use agreed rules called character encoding systems to represent text as numerical values that can be stored and processed.

Example

In ASCII, uppercase A has decimal value 65. Using eight bits, its binary representation is 01000001.

Character: A
ASCII decimal value: 65
Binary representation (8 bits): 01000001

2. What Is Character Encoding?

Character encoding is a system of rules that connects characters with numerical values. These values allow computers to store, send, and display text consistently.

ASCII

ASCII stands for American Standard Code for Information Interchange. It represents 128 standard characters, including English letters, digits, punctuation, and control characters, using 7-bit codes.

An eight-bit byte can also store an ASCII character, with the first bit set to zero.

Unicode

Unicode provides code points for characters from many writing systems, including Dzongkha, English, Chinese, and many others.

UTF-8 is a widely used Unicode encoding. It uses between one and four bytes to encode a Unicode code point.

Important difference: Standard ASCII covers a limited set of characters. Unicode supports a much wider range of characters, making it suitable for international languages and symbols.

3. Examples of Text Representation

Different characters have different numerical values. Here are some familiar examples from standard ASCII.

Character ASCII Decimal 8-bit Binary
A 65 01000001
B 66 01000010
a 97 01100001
0 48 00110000
Space 32 00100000
Uppercase A and lowercase a have different ASCII values. The character "0" is also different from the numerical value zero used in calculations: the character "0" has ASCII decimal value 48.

4. How Does a Computer Store a Word?

A word contains individual characters. In an ASCII example, each character is assigned a numerical value and represented in binary.

Example: The word CAT

Letter Decimal Code 8-bit Binary
C 67 01000011
A 65 01000001
T 84 01010100

The word CAT is represented by three character codes. Each ASCII character uses one byte in the eight-bit format shown.

C → 01000011
A → 01000001
T → 01010100

Real text files may also contain line breaks and other information. Their storage depends on the encoding used.

5. Try It Yourself: Text to Binary

Enter a short word or sentence and choose an encoding to see how the text is represented. This activity runs in your browser and does not send your text to a server.

How to use this activity:
  1. Enter a word, such as DATA.
  2. Choose UTF-8 or Standard ASCII.
  3. Click Convert Text.
  4. Compare the binary values shown for each byte.
  5. Try a number, punctuation mark, or a space.

Standard ASCII accepts only characters with code values from 0 to 127. UTF-8 can encode a much wider range of characters. Characters outside ASCII may require multiple bytes in UTF-8.

6. Why Is Text Representation Important?

Text representation allows computers to exchange information and display written content correctly.

  • Communication: Text can be sent between computers and devices.
  • Documents: Applications can save letters, reports, and written content.
  • Websites: Browsers use character encoding to display text correctly.
  • Programming: Programs process text, characters, and strings.
  • International languages: Unicode and UTF-8 help support many languages.

7. Self-Learning Notes

Note 1: What is a bit?

A bit is the smallest unit of digital information. It can hold either 0 or 1. A group of eight bits is called a byte.

Note 2: What is a character?

A character is an individual symbol used in text. Examples include A, b, 7, ?, and a space.

Note 3: What is a string?

A string is a sequence of characters. For example, "Data Quest" is a string containing letters and a space.

Note 4: Why does encoding matter?

If text is decoded using the wrong encoding, some characters may appear incorrectly. Compatible encoding helps applications display the intended text.

Note 5: ASCII and Unicode are not the same

ASCII is a limited character code standard. Unicode defines code points for a broad range of characters. UTF-8 encodes Unicode code points into bytes.

Note 6: Characters and bytes

A character and a byte are not always the same thing. Standard ASCII characters take one byte in UTF-8, while many other Unicode characters require multiple bytes.

Key points to remember:
  • Computers store text as encoded digital data.
  • Binary digits are 0 and 1.
  • Eight bits make one byte.
  • ASCII represents a limited set of characters.
  • Unicode supports characters from many languages.
  • UTF-8 is a widely used Unicode encoding.
