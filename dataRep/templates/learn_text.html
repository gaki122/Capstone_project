🔤 Data Quest Learning Topic

Text & ASCII

Learn how computers represent letters, numbers, and symbols using digital data.

📝 What is Text Representation?

Computers do not understand letters directly. They store information using numbers and binary digits such as 0 and 1.

Therefore, every character such as a letter, number, or symbol must be represented by a numerical value that a computer can store.

💡 Example

The letter A is represented by the number 65 in ASCII.

The number 65 can then be represented in binary.

A → 65 → 01000001

💻 What is ASCII?

ASCII stands for American Standard Code for Information Interchange .

ASCII is a character encoding system that assigns numerical values to characters. These values allow computers to store and process text.

🔢 Examples

A = 65

B = 66

C = 67

a = 97

b = 98

🔢 Common ASCII Characters

Here are some commonly used ASCII characters and their decimal and binary values.

Space 32 00100000

⚙️ How Does a Character Become Binary?

When a character is stored in a computer, it goes through several stages.

1

Character

The computer receives a character such as A.

2

ASCII Code

The character is assigned a numerical ASCII value.

3

Decimal

The ASCII value is represented as a decimal number.

4

Binary

The number is stored using 0s and 1s.
