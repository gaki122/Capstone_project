1. What is ASCII?

ASCII stands for American Standard Code for Information Interchange. It is a character-encoding standard that assigns numeric codes to English letters, digits, punctuation marks, and control characters.

Computers store and process information using binary digits, which are 0 and 1. ASCII gives supported characters standard numeric values so computers can represent and exchange text.

💡 Example: The letter A

The uppercase letter A has the decimal ASCII value 65.

Its 7-bit binary representation is 1000001.

When displayed using 8 bits, a leading zero is added.

A → 65 → 01000001

2. How Does ASCII Work?

Standard ASCII uses 7 bits and defines 128 codes, numbered from 0 to 127. Seven bits can represent 128 different values.

An ASCII code can be displayed as a 7-bit binary number. It can also be written using 8 bits by adding a leading zero when needed. Standard ASCII itself still defines 128 codes.

Understand the difference

Character: A

Decimal ASCII value: 65

7-bit binary: 1000001

8-bit display: 01000001

7. Advantages and Limitations of ASCII

Advantages

  • Provides standard codes for common English characters.
  • Helps computers exchange basic text consistently.
  • Is useful for learning binary and character encoding.
  • Uses simple codes that are easy to study and understand.

Limitations

  • Standard ASCII contains only 128 codes.
  • It does not cover all world languages and writing systems.
  • Unicode supports a much wider range of characters.

8. Self-Learning Notes

Use these notes to revise important concepts. Read each topic carefully and return to the examples above whenever you need more explanation.

Note 1: Character Encoding

Character encoding is a system that connects characters with numeric codes. Computers use these codes to store, process, and exchange text.

For example, in ASCII, the uppercase letter A is represented by the decimal number 65.

Note 2: Decimal and Binary

Decimal is the number system we commonly use. It uses ten digits, from 0 to 9. Binary is a base-2 number system that uses only two digits: 0 and 1.

The decimal number 65 is written as 1000001 in binary. When displayed in 8 bits, it is written as 01000001.

Note 3: Uppercase and Lowercase Letters

Uppercase and lowercase letters have different ASCII codes. For example, uppercase A has decimal code 65, while lowercase a has decimal code 97.

Changing the case of a letter changes its code.

Note 4: Representing a Word

Each character in a word has its own code. A computer represents the word as a sequence of character codes.

For example, CAT uses the ASCII codes for C, A, and T: 67, 65, and 84 respectively.

Note 5: ASCII and Unicode

Standard ASCII is limited to 128 codes and does not represent all characters used around the world. Unicode supports characters from many languages and writing systems.

UTF-8 is a widely used way to encode Unicode text. It is compatible with standard ASCII for the first 128 code values.

Important Points to Remember

  • ✓ ASCII stands for American Standard Code for Information Interchange.
  • ✓ Standard ASCII has 128 codes, numbered from 0 to 127.
  • ✓ Binary uses only the digits 0 and 1.
  • ✓ The decimal ASCII value of uppercase A is 65.
  • ✓ Uppercase A in 8-bit binary is 01000001.
  • ✓ Different characters can have different ASCII codes.
  • ✓ Unicode supports a much wider range of characters than ASCII.
