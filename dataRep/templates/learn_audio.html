Learn Audio Representation

Discover how computers record, represent, store and play sound using digital data. Learn about sampling, sample rate, bit depth and common audio file formats.

1. What Is Digital Audio?

Audio is sound that we can hear, such as speech, music, singing, birds and other environmental sounds.

Computers cannot directly store sound in the same way that our ears hear it. They convert sound into digital information represented using binary digits: 0 and 1.

This process allows computers, mobile phones and other devices to record, store, edit and play sound.

Example: When you record your voice using a mobile phone, the phone converts the sound into digital data and saves it as an audio file.

Illustration: sound can be represented by a changing waveform.

2. How Is Sound Converted into Digital Data?

Digital audio is commonly created through a process called analog-to-digital conversion.

Step 1: Sound Wave

A microphone receives sound vibrations and produces an electrical signal that changes with the sound.

Step 2: Sampling

The system measures the signal at regular time intervals. Each measurement is called a sample.

Step 3: Quantization

Each measurement is assigned a digital value from a set of available levels.

Step 4: Binary Storage

The digital values are encoded as binary data and stored in an audio file.

Remember: Sampling measures sound over time, while quantization represents the measured amplitudes using discrete numerical levels.

3. What Is Sampling?

Sampling is the process of measuring a sound signal at regular intervals to represent it digitally.

The number of samples taken per second is called the sample rate. It is measured in hertz (Hz).

  • 8,000 Hz: 8,000 samples each second.
  • 22,050 Hz: 22,050 samples each second.
  • 44,100 Hz: 44,100 samples each second.
  • 48,000 Hz: 48,000 samples each second.
Example: CD audio commonly uses a sample rate of 44,100 Hz, meaning that 44,100 samples are taken per second for each channel.

Why Does Sample Rate Matter?

A higher sample rate can represent higher-frequency details, provided the recording and playback systems support them. It can also increase the amount of audio data when other settings remain unchanged.

The sample rate alone does not determine overall sound quality. Microphone quality, recording conditions, bit depth and compression also matter.

4. What Is Bit Depth?

Bit depth describes how many bits are used to represent each audio sample in common uncompressed PCM audio. It affects how precisely sample amplitudes can be represented.

Bit Depth Possible Quantization Levels General Description
8-bit 256 Fewer levels; limited precision
16-bit 65,536 Common for CD-quality PCM audio
24-bit 16,777,216 Common in professional recording workflows

The number of theoretical levels is calculated using 2bit depth.

Example: For 16-bit audio, the number of possible quantization levels is 216 = 65,536.

A higher bit depth can reduce quantization noise and provide greater dynamic range. It also uses more data per sample in uncompressed audio.

5. What Is a Bit Rate?

Bit rate describes how many bits of audio data are processed or stored per second. It is commonly measured in kilobits per second (kbps).

  • 128 kbps: a common compressed-audio setting.
  • 256 kbps: a higher compressed-audio bit rate.
  • 320 kbps: a high bit rate used by some MP3 encoders.

For many compressed formats, a higher bit rate can preserve more audio detail, but the result also depends on the encoder, format and original recording.

Important distinction: Sample rate is measured in samples per second. Bit depth is measured in bits per sample. Bit rate is measured in bits per second. They describe different things.

6. How Is Audio File Size Calculated?

For uncompressed PCM audio, an approximate file data size can be calculated using:

Audio size in bits =

Sample rate × Bit depth × Number of channels × Duration

Let's calculate the approximate data size for a 10-second recording:

  • Sample rate: 44,100 samples per second
  • Bit depth: 16 bits
  • Channels: 2 (stereo)
  • Duration: 10 seconds

44,100 × 16 × 2 × 10 = 14,112,000 bits

14,112,000 ÷ 8 = 1,764,000 bytes, or approximately 1.76 MB before file headers and other overhead.

This is an estimate for uncompressed PCM data. Compressed formats such as MP3 can produce much smaller files, while actual sizes depend on encoding settings and file metadata.

7. Common Audio File Formats

MP3 (.mp3)

A widely supported lossy compressed audio format. It can make music files much smaller, with some audio information discarded during compression.

WAV (.wav)

A container commonly used for uncompressed PCM audio. It is useful for recording and editing but can require considerable storage space.

AAC (.aac, .m4a)

AAC is a lossy compression format used by many devices and streaming services. The .m4a extension commonly identifies an audio file in an MP4 container.

FLAC (.flac)

A lossless compressed format. It reduces file size while preserving the original audio data.

OGG (.ogg)

Ogg is a multimedia container. It often stores Vorbis or Opus audio, depending on how the file was created.

AIFF (.aiff, .aif)

An audio file format used in some recording and editing workflows, often for uncompressed audio.

Quick comparison: Lossy formats reduce file size by discarding some audio information. Lossless formats reduce file size without losing the original encoded audio data. Uncompressed audio keeps the PCM samples without compression.

8. Mono and Stereo Audio

Mono

Mono audio has one audio channel. It is often suitable for voice recordings, announcements and spoken lessons.

Stereo

Stereo audio has two channels: left and right. It can create a sense of space and direction when played through suitable headphones or speakers.

Example: A classroom voice recording might use mono audio, while a music recording may use stereo to represent sounds across left and right channels.

9. Where Is Digital Audio Used?

  • Music streaming and music players.
  • Mobile phone voice recordings.
  • Online classes and educational videos.
  • Video games and computer applications.
  • Podcasts, radio and voice messages.
  • Voice and video calls.
  • Audio editing, sound production and digital media.

10. Self-Learning Notes

Important Terms to Remember

  • Digital audio: Sound represented as digital data.
  • Sampling: Measuring a sound signal at regular intervals.
  • Sample rate: Number of samples taken per second.
  • Bit depth: Number of bits used to represent each sample.
  • Bit rate: Amount of audio data processed per second.
  • Mono: Audio with one channel.
  • Stereo: Audio with two channels.
  • Lossy compression: Reduces file size by discarding some information.
  • Lossless compression: Reduces file size without losing the original encoded data.

Key Points

  • Computers represent digital audio using binary data.
  • Sampling measures a signal at regular time intervals.
  • Sample rate is measured in hertz.
  • Bit depth affects the precision of sample amplitude representation.
  • More channels increase uncompressed audio data size.
  • Compression can reduce the size of audio files.
  • Different audio formats are designed for different uses.

Try This at Home

  4. Compare a voice recording with a music file.
  5. Explore the audio settings in a recording or editing application.
