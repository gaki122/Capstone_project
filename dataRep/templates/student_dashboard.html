📚 Learn More

Before playing the games, understand the basic ideas behind digital data representation.

🔤 ASCII

ASCII stands for American Standard Code for Information Interchange. It gives characters such as letters, numbers, and symbols numerical codes that computers can understand.

📝 Text

Computers store text using numerical representations. Different character encoding systems allow computers to store and display written information.

🖼️ Image

Digital images are made from small elements called pixels. Each pixel contains numerical information representing its colour.

🎵 Audio

Digital audio represents sound using numerical samples. The computer stores these samples so that sound can be processed, stored, and played back.
